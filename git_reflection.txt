GIT REFLECTION

1. Git is used for:
Tracking changes in source code and managing different versions of a project.

2. GitHub is used for:
Storing Git repositories online and collaborating with other developers.

3. A commit means:
Saving a recorded set of changes in the project's Git history.

4. A branch is used for:
Working on new features without directly affecting the main project.

5. A Pull Request is used for:
Requesting a review of changes before merging them into another branch.
